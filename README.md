# Miracle Code · 奇迹代码 — Make a wish come true

Entertainment AI-divination web app for the Zurich Hackathon (27–28 Nov 2026). Date: 2026-10-24 (v0.4).

Silently make a wish, spin three 1–99 slot reels, and get a Meihua Yishu (梅花易数) I Ching reading (primary / process / outcome hexagrams, five-element Body/Use) with a 0–100 fortune score, strengths, weaknesses and advice — framed by the real night sky above you (IAU 88 constellations computed for your location and time).

- 9 languages: 中文, English, Deutsch, Italiano, Français, Español, Português, Svenska, Suomi
- Voice read-aloud and voice wish input in the selected language
- Free reading; Stage 2 paid detailed reading by category (demo)
- Single self-contained `index.html`, no dependencies

Constellation data: d3-celestial by Olaf Frohn (BSD-3-Clause).
⚠️ For entertainment only.
